About Django Auth System

This is a simple authentication system built with Django.

The system uses Django's built-in User model and authentication framework.

Features:

  • User Registration with email validation
  • Secure Password Hashing
  • User Login with Session Management
  • Protected Dashboard for logged-in users
  • User Logout functionality
  • Password confirmation validation
  • Duplicate email prevention
  • CSRF Protection

Built with Django 6.0.3 & SQLite3
